# Sistema de Autenticação e Personalização em PHP

Este é um projeto simples e funcional em PHP que demonstra o gerenciamento de sessões, autenticação de usuário e personalização da interface gráfica em tempo real.

---

## 📌 Funcionalidades

- **Autenticação de Usuário**: Sistema simples de login e validação de credenciais.
- **Gerenciamento de Sessão**: Mantém o usuário conectado e armazena suas preferências utilizando `$_SESSION`.
- **Personalização da Interface**: Permite ao usuário escolher e salvar a cor de fundo da página de perfil através de um seletor de cores (`input type="color"`).
- **Logout Seguro**: Encerramento da sessão e redirecionamento para a tela inicial/login.

---
